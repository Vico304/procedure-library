# 目录复制与一致性核对

将 `source` 中的普通文件和目录完整复制到 `target`，包含隐藏文件和空目录，核对相对路径与文件 SHA-256。输入均来自本次参数，不使用原任务中的固定路径。

1. 确认 source 是目录，source 与 target 不相同、不互相包含。源目录中的符号链接不属于本流程，发现时停止。
2. 运行本流程附带的 `scripts/copy_directory.py --source <source> --target <target>`。使用正确的参数传递，路径中可能有空格或非英文字符。
3. 脚本在复制前检查目标：目标不存在时复制；目标已完全相同时直接核对成功；目标有任何不同或不是目录时停止，不能覆盖、合并或删除目标。
4. 脚本核对目标结构和文件 SHA-256 后输出状态。观察实际结果，再返回 success、blocked 或 failed；遇到冲突说明原因，不自行清空目标。

目标：实际目标树与源树一致，源内容保持原样。失败或中断留下的目标交回当前任务判断；本流程不自动清理或重试。它只验证复制完整性，不判断被复制内容的业务语义，也不发布到外部系统。
